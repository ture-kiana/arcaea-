Arcaea / 韵律源点 b50 导出工具 v1.0
========================================

【它是什么】
  从手机本地存档（st3）直接算出 b50 和 PTT，导出 CSV、生成卡片，
  并附带一个完整分析页（PTT 历史曲线、P50/LS0/MAX 排行、定数查询、图片导出）。
  全程本机处理，不联网、不上传、不需要账号密码。

【怎么用】
  1. 双击 ArcaeaB50.exe，会自动弹出浏览器界面。
  2. 第 1 步：在界面里选中你的手机品牌，照着把「USB 调试」打开。
  3. 第 2 步：数据线连电脑，手机弹窗选「允许」（勾一律允许），
     通知栏 USB 用途选「传输文件」，然后点「检测连接」。
  4. 第 3 步：选国服 / 国际服，点「开始读取」，几秒钟出结果。
  5. 结果页可以「补全曲绘」「打开完整分析」「打开数据文件夹」。
  6. 用完点页面底部「退出程序」。

【读不到怎么办】
  · 界面里每一步的报错都写了原因，按提示改。
  · 实在读不出来（手机没 root 且包不是 debug 版），
    点「手动选择 st3 文件」导入，获取方式见界面最后一节教程。
  · 纯血鸿蒙 HarmonyOS NEXT 没有 adb、iPhone 拿不到沙箱文件，
    这两类请借一台安卓机，或用「手动导入」。

【计算口径（v7.0 起）】
  单曲潜力值 = 定数 + 分档加成 + 0.2（通关奖励，TL 不加）
    ≥1000 万 → 定数 + 2
    ≥980 万  → 定数 + 1 + (分数 - 980万) / 200000
    <980 万  → 定数 + (分数 - 950万) / 300000（下限 0）
  整体 PTT = (b50 总和 + b10 总和) ÷ 60     ← 前 10 名双倍权重

【数据放哪】
  %LOCALAPPDATA%\ArcaeaB50\
    jackets\   曲绘
    data\      all_scores.csv / ratings.csv
  删掉这个目录即可清空缓存。

【说明】
  · 本工具只读取游戏数据，不修改任何内容。
  · 曲目定数为社区整理，与游戏内可能有极小误差；新曲未收录时会提示。
  · 存档里只有「每个谱面的最佳成绩」，所以历史曲线是阶梯状，
    不是每一局的历史。
  · 请不要在网吧等公共电脑上使用，存档包含你的游戏数据。
