# 手机端导出教程

程序界面里的教程和这份内容一致，这里留一份纯文本版方便搜索。

## 通用前提

1. 数据线必须**支持数据传输**（很多充电线只有电流，插上只会充电）
2. 手机通知栏的 USB 用途选 **传输文件 / MTP**，选「仅充电」电脑看不到设备
3. 手机弹「是否允许 USB 调试」时，勾 **一律允许使用这台计算机进行调试** 再点允许
4. Windows 识别不到设备：华为装 HiSuite、小米装小米助手，或装通用 ADB 驱动

## 华为 / 荣耀（HarmonyOS 4.x、MagicOS）

1. 设置 → 关于手机 → 连续点「版本号」7 次（可能要输锁屏密码）
2. 返回 设置 → 系统和更新 → 开发人员选项
3. 打开「USB 调试」，顺手打开「仅充电模式下允许 ADB 调试」
4. 插线后下拉通知栏 → 点「正在通过 USB 充电」→ 选 传输文件

> 注意：**纯血鸿蒙 HarmonyOS NEXT 5.x 没有 adb**（只有 hdc），也装不了安卓包。这类机器请换安卓设备，或用「手动导入」。

## 小米 / 红米（MIUI 14、HyperOS）

1. 设置 → 我的设备 → 全部参数与信息 → 连续点「MIUI 版本 / OS 版本」7 次
2. 设置 → 更多设置 → 开发者选项
3. 打开「USB 调试」
4. 插线选 传输文件

> 最常见的坑：**必须登录小米账号并插着 SIM 卡**，否则打开 USB 调试时会提示「验证失败，请插入 SIM 卡」。个别机型还要打开「USB 调试（安全设置）」，同样需要登录账号。

## OPPO / 一加 / realme（ColorOS、realme UI）

1. 设置 → 关于本机 → 版本信息 → 连续点「版本号」7 次
2. 设置 → 系统设置（部分机型在「其他设置」）→ 开发者选项
3. 打开「USB 调试」，插线选 传输文件

## vivo / iQOO（OriginOS、Funtouch）

1. 设置 → 系统管理 → 关于手机 → 连续点「软件版本号」7 次
2. 设置 → 系统管理 → 开发者选项
3. 打开「USB 调试」

> OriginOS 的开发者选项在「系统管理」里，不在「更多设置」。

## 三星（One UI）

1. 设置 → 关于手机 → 软件信息 → 连续点「版本号」7 次
2. 设置 → 最下面 开发者选项 → 打开「USB 调试」
3. 插线后 USB 用途选 传输文件

## 魅族 / 努比亚 / 其它（Flyme、MyOS）

1. 设置 → 关于手机 → 连续点「版本号」7 次
2. 回设置找 开发者选项（Flyme 在「辅助功能」里）→ 打开 USB 调试
3. 找不到就在设置顶部搜索框搜「开发者」

## 原生安卓 / Pixel

1. 设置 → 关于手机 → 连续点「版本号」7 次
2. 设置 → 系统 → 开发者选项 → 打开 USB 调试
3. 插线选「文件传输」并允许这台电脑调试

## iPhone / iPad

本工具依赖 adb，只支持安卓。iOS 存档在应用沙箱内，未越狱无法取出。

替代方案：用一台安卓手机登录同一国服账号，同步一次成绩，再用本工具导出。

## 手动导入 st3（兜底）

1. **有 root 的安卓**：用 MT 管理器进 `/data/data/com.xd.arcaea.tapcn/files/`，把 `st3` 复制到内部存储，再传到电脑
2. **没有 root**：用 LSPatch + 上传模块（社区有 `arc_st3_upload` 一类模块），在游戏里点上传把 st3 导出
3. **电脑模拟器**：从模拟器共享文件夹直接拷 `st3`（路径同上）

拿到文件后，在程序界面点「手动选择 st3 文件」导入，效果与自动读取完全一致。

> `st3` 是纯 SQLite 明文文件，不加密，只要拿到就能算。
